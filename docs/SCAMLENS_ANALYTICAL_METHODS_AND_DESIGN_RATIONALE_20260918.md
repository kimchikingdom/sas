# ScamLens 프로젝트 분석 방법론 및 설계 채택 이유 총람 (2026-09-18)

## 1. 개요 (Executive Summary)

**ScamLens**는 기존 머신러닝 스미싱 탐지 연구들이 가지고 있던 고질적인 문제점인 **① 데이터 교차 오염(Data Leakage/Snooping), ② URL 편향에 따른 지름길 학습(Shortcut Learning), ③ 비현실적인 오탐률(High FPR), ④ 온디바이스 배포 한계(Resource Overhead), ⑤ 개인정보 암기 공격(PII Memorization)**을 원천 차단하기 위해 설계된 엔드투엔드 보안 방어 프레임워크입니다.

본 문서는 프로젝트 전반에서 적용된 **8대 핵심 분석 방법론**의 구체적인 수학적·알고리즘적 원리와, 각 기법을 채택한 실무적·보안적 근거를 상세히 기록합니다.

### 방법론 1: 유사도 그룹 기반 계층 분할 (Cluster-aware Similarity Group Stratification)

#### 1) 분석 방법의 세부 내용
* 원문 텍스트에 대해 토큰 기반 및 MinHash/LSH 자카드 유사도를 계산하여 유사 문장들을 1,543개의 **유사도 그룹(Development Group)**으로 클러스터링했습니다.
* 데이터를 학습(Train), 검증(Validation), 테스트(Test)로 분할할 때 개별 행(Row)을 무작위로 섞는 대신, **그룹 단위(Group-level)로 분할하여 동일 그룹에 속한 변형 문자가 서로 다른 세트에 교차 배정되지 않도록 물리적으로 격리**했습니다.

#### 2) 채택 이유 및 배경
* **기존의 한계 (Data Snooping / Memorization Leakage)**:
  - 스미싱 문자는 특정 범죄 조직이 하나의 템플릿(예: `[국외발신] 결제완료 USD 840...`)에서 숫자나 날짜만 조금씩 바꿔 대량 발송합니다.
  - 기존 학계 연구처럼 단순 무작위 분할(Random Split)을 적용하면, 동일한 템플릿의 문자가 학습셋과 테스트셋에 동시에 들어가 모델이 "본문의 범죄 패턴"을 배우는 것이 아니라 "템플릿 문자열 자체를 암기"하여 99% 이상의 거짓 높은 정확도를 기록하게 됩니다.
* **채택 효과**:
  - 미지의 신종 변형 스미싱이 들어왔을 때의 **실제 야생(In-the-Wild) 일반화 탐지 능력**을 엄격하게 측정할 수 있습니다.

### 방법론 2: 15조건 Matched Control 인과 대조 설계 (Paired Counterfactual Control)

#### 1) 분석 방법의 세부 내용
* 데이터셋을 3가지 조건(Arm)으로 체계적으로 변형하고, 각 조건마다 5개의 난수 시드(42, 101, 202, 303, 404)를 적용하여 총 15개 모델을 독립 훈련·평가했습니다:
  - **Arm A (BASE)**: 자연스러운 원본 상태 그대로의 데이터.
  - **Arm B (FLIP)**: 악성 메시지의 URL을 중립 토큰으로 마스킹하거나 제거(Sanitized)하여 모델이 본문 문맥만을 읽도록 강제.
  - **Arm C (DUP)**: 정상 상용 메시지에 인위적으로 benign URL을 결합하여, URL 존재로 인한 오탐 민감도를 스트레스 테스트.
* 추가로 URL 편집으로 인해 의미가 변형될 위험이 있는 16개 난해 케이스에 대해 **인간 검수자 사후 재확인(U2 Audit)**을 수행하여 14건의 의미 변화와 2건의 판단 불가를 확정했습니다.

#### 2) 채택 이유 및 배경
* **기존의 한계 (Shortcut Learning / Confounder Bias)**:
  - 공공 데이터셋에서는 악성 문자에는 거의 항상 URL이 붙어 있고, 정상 문자에는 URL이 적습니다.
  - 이로 인해 신경망 모델은 문맥을 분석하지 않고 **"URL 토큰이 있는가?"라는 가장 쉬운 지름길(Shortcut)**만 학습합니다. 그 결과 정상적인 카드 승인 안내나 택배 배송 링크를 무조건 스미싱으로 차단하는 재앙적인 오탐이 발생합니다.
* **채택 효과**:
  - URL이라는 교란 변수(Confounder)를 인위적으로 통제함으로써, 모델이 학습하는 판단 근거가 **"단순 URL 문자열"인지 "언어학적 범죄 의도(맥락)"인지를 인과적으로 분리(Decoupling)**하여 규명했습니다.

### 방법론 3: 네이만-피어슨(Neyman-Pearson) 엄격한 오탐률 보정 (Strict FPR $\le 1.0\%$)

#### 1) 분석 방법의 세부 내용
* 일반적인 임계값(0.5)을 사용하지 않고, 검증 세트(Validation Set)에서 다음의 최적화 문제를 풀어 분류 임계값 $\tau^*$를 결정했습니다:
$$\tau^* = \arg\max_{\tau} \left\{ \text{F1}(\tau) \;\middle|\; \text{FPR}(\tau) \le 0.010 \right\}$$
* 테스트 세트에서는 이 고정된 $\tau^*$를 단 1회 적용하여 최종 성능을 측정했습니다.

#### 2) 채택 이유 및 배경
* **기존의 한계 (비현실적인 임계값과 FPR 무시)**:
  - 대다수 논문은 ROC-AUC나 기본 0.5 임계값 기준의 정확도만 제시합니다. 그러나 실제 통신망에서 오탐률이 3~5%에 달하면, 하루 수십만 건의 정상 비즈니스 알림과 2차 인증(2FA) 문자가 차단되어 서비스 장애를 일으킵니다.
* **채택 효과**:
  - 규제 및 실무 요구선인 **"오탐률 1% 이하"를 제1제약 조건으로 사전 강제**함으로써, 보안 실무에 즉시 투입 가능한 안전성을 수학적으로 보증했습니다.

### 방법론 4: Brier Score 기반 불확실성 및 확률 보정 평가 (Uncertainty & Calibration)

#### 1) 분석 방법의 세부 내용
* 모델이 출력한 연속 확률값 $P(y_i=1)$과 실제 참값 $y_i \in \{0, 1\}$ 간의 평균 제곱 오차를 Brier Score로 측정했습니다:
$$\text{Brier} = \frac{1}{N} \sum_{i=1}^N (P(y_i = 1) - y_i)^2$$
* 15개 모델 및 1,543개 유사도 그룹별 Brier 점수 분포를 계산하여 모델의 확신도 편차를 추적했습니다.

#### 2) 채택 이유 및 배경
* **기존의 한계 (과신 현상 / Overconfidence)**:
  - 현대 심층 신경망(BERT 등)은 예측이 틀렸을 때도 99%의 극단적인 확신도로 틀리는 "과신(Overconfidence)" 문제를 지닙니다.
* **채택 효과**:
  - 단순 정답/오답(0/1)뿐 아니라 **모델이 자신의 예측 확률을 얼마나 솔직하고 정밀하게 신뢰할 수 있는지**를 측정했습니다.
  - FLIP 조건이 가장 낮은 Brier Score(0.01158)를 기록하여 불확실성이 가장 잘 보정되었음을 증명했습니다.

### 방법론 5: 4대 오류 전이 동역학 분석 (Four-category Error Transition Analysis)

#### 1) 분석 방법의 세부 내용
* DUP 모델 대비 FLIP 모델을 적용했을 때 각 샘플의 오차 상태 변화를 4대 범주로 분해하여 집계했습니다:
  1. **정상 오탐 해소 (`resolved_fp`)**: DUP에서 오탐 $\rightarrow$ FLIP에서 정상 분류 (25건, URL 비율 92.0%)
  2. **악성 정탐 손실 (`lost_tp`)**: DUP에서 정탐 $\rightarrow$ FLIP에서 미탐 (22건, URL 비율 63.6%)
  3. **신규 정상 오탐 (`new_fp`)**: DUP에서 정상 $\rightarrow$ FLIP에서 오탐 (2건)
  4. **악성 미탐 구제 (`rescued_fn`)**: DUP에서 미탐 $\rightarrow$ FLIP에서 정탐 (1건)

#### 2) 채택 이유 및 배경
* **기존의 한계 (블랙박스 식 지표 비교)**:
  - 모델 A와 B의 F1 점수가 비슷하면(예: DUP 96.52% vs FLIP 96.54%), 기존 접근법은 두 모델의 내부 작동 메커니즘 차이를 설명하지 못합니다.
* **채택 효과**:
  - **정상 오탐 해소 25건 중 92%가 URL이 포함된 정상 문자**였다는 사실을 밝혀냄으로써, FLIP 모델이 성능 지표 뒤에 숨겨진 **URL 편향을 완벽히 교정했음을 정량적으로 증명**했습니다.

### 방법론 6: 이중 경로 동적 신뢰도 게이팅 (Two-Track Dynamic Confidence Gating)

#### 1) 분석 방법의 세부 내용
* 두 개의 상호보완적 분류기를 동적으로 결합하는 융합 아키텍처를 구축했습니다:
  - **Track 1**: 문맥 이해에 탁월한 심층 언어 모델 (KcBERT).
  - **Track 2**: 도메인 엔트로피, 단축 URL 시그니처, 텍스트 구조 기반 경량 휴리스틱 분류기.
* 텍스트 길이 $L = |x|$와 KcBERT의 예측 엔트로피 $\mathcal{H}$를 기반으로 게이팅 가중치 $\alpha(x)$를 동적 산출:
$$\alpha(x) = \alpha_{\max} \cdot \exp\left( -\frac{\max(0, L - 35)^2}{2\sigma^2} \right) \cdot (1 - \mathcal{H})$$
$$\hat{S}(x) = (1 - \alpha(x)) \cdot P_{\text{BERT}}(x) + \alpha(x) \cdot P_{\text{Aux}}(x)$$

#### 2) 채택 이유 및 배경
* **기존의 한계 (단문 맥락 부재 및 단일 모델 한계)**:
  - 4대 오류 전이 분석 결과, FLIP 모델은 정상 오탐을 25건 줄였으나 악성 정탐 22건을 놓쳤습니다. 특히 **35자 미만의 초단문 스미싱**에서는 언어 모델이 참조할 문맥이 부족하여 탐지력이 떨어졌습니다.
* **채택 효과**:
  - 단문이거나 모호한 메시지에서는 Track 2의 구조적 규칙이 개입하도록 가중치를 실시간 조절하여, **손실되었던 악성 정탐 중 4건(15.4%)을 즉시 회복**하고 최종 F1을 **96.66%**로 끌어올렸습니다.

### 방법론 7: 온디바이스 ONNX 컴파일 및 INT8 비대칭 동적 양자화 (On-Device Optimization)

#### 1) 분석 방법의 세부 내용
* PyTorch 가중치를 ONNX Opset 17 그래프로 내보내고 동적 축(Dynamic Axes)을 지원하도록 설계했습니다.
* 연산 지연이 큰 Linear 레이어들에 대해 **비대칭 동적 INT8 양자화(Dynamic Quantization)**를 적용하고, CPU 멀티스레드 환경에서 레이턴시(p50, p95) 및 수치 오차(MAE)를 벤치마크했습니다.

#### 2) 채택 이유 및 배경
* **기존의 한계 (클라우드 전송에 따른 개인정보 침해 & 무거운 딥러닝 모델)**:
  - 400MB가 넘는 BERT 모델을 모바일 기기에 직접 탑재하기 어렵고, 그렇다고 사용자 문자를 클라우드 서버로 보내서 검사하면 통신 비밀 침해 및 감청 논란이 발생합니다.
* **채택 효과**:
  - 모델 용량을 **415.5MB에서 104.6MB로 74.8% 압축**하고, 추론 시간을 **55.66ms에서 17.77ms로 3.13배 가속**하여, **외부 네트워크 연결 없는 완전한 온디바이스 백그라운드 필터링**을 가능하게 만들었습니다.

### 방법론 8: 제로 트러스트 프라이버시 거버넌스 (Zero-Trust Privacy Governance)

#### 1) 분석 방법의 세부 내용
* 2026-09-18 연구 책임자 승인을 통해 4대 거버넌스 정책을 확정·봉인했습니다:
  1. 로컬 비영리 연구 및 실험: **[승인] 허용**
  2. 통계 집계 표, 차트, 논문 공개: **[승인] 허용**
  3. 원문 문자열 및 편집 텍스트 재배포: **[확정] 비공개 폐쇄 격리 (`0700`)**
  4. 파인튜닝된 KcBERT 모델 가중치 호스팅: **[확정] 비공개 폐쇄 격리 (`0700`)**

#### 2) 채택 이유 및 배경
* **기존의 한계 (언어 모델의 개인정보 암기 공격 / Memorization Attack)**:
  - 최신 보안 연구(Carlini et al., USENIX Security 2021)에 따르면, 딥러닝 언어 모델은 학습 데이터에 포함된 전화번호, 계좌번호, 실명을 가중치 내부에 그대로 암기하며, 프롬프트 주입 공격을 통해 원문을 역추출해낼 수 있습니다.
* **채택 효과**:
  - 원문 텍스트뿐만 아니라 학습된 체크포인트 자체를 외부에 배포하지 않고 오프라인 격리함으로써, **제3자 개인정보 침해 위험을 100% 원천 차단**했습니다.
