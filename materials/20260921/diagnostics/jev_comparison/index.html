완료 상태

오류를 과대표집한 사후 진단의 집계만 보여준다. 개별 행·원문·개별 점수는 이 페이지에 포함하지 않는다.

  • 코퍼스 라벨은 검증된 사기 정답이 아니며, 본문 요구 기반 대리 분류와 비교한 결과다.
  • 오류군을 과대표집했으므로 전체 정확도·실서비스 오탐률로 일반화하지 않는다. 독립 시험·인과 주장에 사용하지 않는다.
  • 가상 대체(해소·신규 오류)는 Jev 판정으로 모델 판정을 대체한다고 가정한 계산이며, 원본 코퍼스 라벨은 변하지 않는다. 검토 큐는 사람 검토 후보 집계일 뿐 실제 수정이 아니다.
  • 보류(판정 불가)는 판정 분모에 포함하지 않는다.
