## 1. Executive Summary (연구 요약)

본 연구는 "정상 문자를 위협하지 않으면서 스미싱(Smishing) 문자를 정밀하게 탐지하기 위해 무엇을 검증해야 하는가?"라는 질문에서 출발하였다. 스미싱 탐지 모델이 흔히 겪는 결함은 악성 문자에 빈번히 등장하는 URL 링크나 표면 키워드에 과적합(지름길 학습, Shortcut Learning)되어 링크를 포함한 정상 문자를 오탐(False Positive)하거나, 링크가 생략된 스미싱을 미탐(False Negative)하는 문제이다.

ScamLens 프로젝트는 과장된 수치 경쟁을 지양하고 다음과 같은 연구 성과와 의사결정을 도출하였다:

1. **SAS 기반 모형 비교 분석 (SAS 서버 실행 분석)**:
   - 본문 문자 모형(단독 AUC 0.9987)과 URL 모형의 결합 효과를 SAS 서버 환경에서 검증하였다. 고정가중 결합 모형의 관측 AUC는 0.995로 문자 단독보다 낮았다.
   - OOF 메타 결합 모형(AUC 0.9988) 역시 문자 단독 대비 통계적으로 유의한 순위 차이가 검출되지 않았다(estimate -0.00006, 95% CI [-0.00039, 0.000267], p = 0.7233).
   - 이는 두 모형의 동등성 증명이 아니며 차이가 검출되지 않았음을 의미한다. 이를 바탕으로 단순 결합 채택을 보류하고, 단일 언어모델(KcBERT) 본체의 맥락 검증에 집중하기로 결정하였다.

2. **동일 계산 예산 하의 통제 대조실험 설계 (BASE vs DUP vs FLIP)**:
   - 정제 코퍼스 6680건을 기반으로, 승인 교란 코호트 E(281건)의 주입 방식을 통제한 세 가지 실험군을 구축하였다:
     - **BASE**: 기본 정제 훈련셋(6680건).
     - **DUP**: 승인 E 원본을 단순 복제 주입한 훈련셋(6961건).
     - **FLIP**: 승인 E의 원본 레이블(정상/스미싱)을 보존한 채 URL 유무만을 교란 주입한 훈련셋(6961건).
   - 세 실험군 모두 동일한 654 업데이트 스텝(동일 계산 예산)과 5개 난수 시드(42, 101, 202, 303, 404)를 적용하였다.
   - 이전 09-17 가중치가 보존되지 않아 로컬 Python/MPS 환경에서 새로 재학습을 수행하여 평가 모델들을 구성하였다.

3. **개발 탐색 관찰과 U5 후속 평가의 재현성 검증**:
   - 개발 탐색 코호트(1750건)에서는 5개 시드 누적 예측 사건 기준 FLIP이 DUP 대비 오탐 25건을 해결하고 신규 오탐 10건을 발생시켜(순 오탐 감소 15건), 오탐률(FPR)이 0.89%에서 0.68%로 낮게 관찰되었다.
   - 그러나 원래 test 분할(2317건)에 대한 U5 후속 평가에서 검증한 결과, DUP(FPR 0.44% ± 0.11%)과 FLIP(FPR 0.46% ± 0.18%) 간의 오탐률 개선은 이어지지 않았다. Recall(DUP 97.88% vs FLIP 97.55%)과 Brier Score(DUP 0.0090 vs FLIP 0.0117)도 함께 보고한다. 이는 관측 평균이며 통계적 우월성 판정은 아니다.

4. **신중한 공학적 의사결정**:
   - 개발 데이터의 일시적 관찰에 기댄 FLIP의 자동 채택을 보류하고, 통계적 동등성이나 우월성을 자의적으로 주장하지 않았다.
   - FLIP의 자동 채택을 보류하고 단순 대조군(DUP)을 다음 연구 비교 기준으로 유지하며, 향후 신규 외부 독립 자료에서의 추가 검증 필요성을 명시하였다.
   - 모든 사례에 대한 사람 검수가 완료된 것이 아니며 자동 규칙 정제에 따른 잔여 한계가 존재함을 밝힌다.

## 2. 연구 배경 및 문제 정의

스미싱 탐지 시스템이 실환경에 배포될 때 중요한 문제는 정상 알림 문자나 모바일 청첩장 등 정상 문자를 차단하는 오탐(False Positive)이다. 악성 문자에 URL이 자주 포함된다는 데이터셋 내 표면적 편향에 과적합되면, 링크가 있는 정상 문자를 오탐하거나 링크가 생략된 고도화 피싱을 미탐하게 된다.

본 연구는 세 가지 질문을 검증하였다:
- **RQ 1**: 본문 텍스트 모형과 URL 모형의 결합은 단일 본문 모형보다 통계적으로 우수한가?
- **RQ 2**: 정상 문자의 URL 지름길 학습을 방지하기 위해 원본 레이블을 보존한 URL 교란 데이터(FLIP)를 주입할 때, 단순 복제(DUP) 대비 오탐률 감소가 나타나는가?
- **RQ 3**: 개발 단계(Development Readout)에서 관찰된 지표 개선은 고정된 평가 프로토콜 하의 원래 test 분할(U5 후속 평가)에서도 이어지는가?

## 4. SAS 통계 분석과 의사결정

SAS 서버 환경에서 5-Fold OOF를 메타 모형 학습 입력으로 사용하고 테스트 분할(where split='test')에서 ROC 분석을 수행한 결과:

| 모형 구성 | AUC | 문자−OOF 차이 | 95% 신뢰구간 (CI) | $p$-value | 판정 |
|---|---|---|---|---|---|
| **문자 모형 단독** (기준) | **0.9987** | - | - | - | 기준 모형 |
| **고정가중 결합 모형** | 0.995 | - | - | - | 관측 AUC 하락 |
| **SAS OOF 메타 모형** | 0.9988 | -0.00006 | [-0.00039, 0.000267] | 0.7233 | 차이 미검출 |

- **분석 결론**: 고정가중 결합의 관측 AUC는 문자 단독보다 낮았다. OOF 메타 모형 역시 문자 단독과의 차이가 신뢰구간과 p값에서 검출되지 않았다($p = 0.7233$). 이는 두 모형의 동등성 증명이 아니며 유의한 차이가 검출되지 않았음을 의미한다.
- **의사결정**: 단순 결합 가정을 채택할 수 없다는 판단에 따라, 복잡한 결합 대신 단일 언어모델(KcBERT)의 통제 대조실험에 집중하기로 결정하였다.

## 5. KcBERT 통제 대조실험 설계 (BASE vs DUP vs FLIP)

- **BASE**: 기본 훈련 코호트 6680건
- **DUP**: 기본 6680건 + 승인 교란 코호트(E) 281건 복제 = 6961건
- **FLIP**: 기본 6680건 + 승인 교란 코호트(E) 281건의 레이블 보존 URL 교란 = 6961건
- **통제 조건**: 세 실험군 모두 동일한 654 업데이트 스텝(동일 계산 예산), 5개 난수 시드(42, 101, 202, 303, 404) 적용.

- **평가 프로토콜**: 훈련 내부 캘리브레이션 셋(1703건)에서 FPR <= 1.0% 임계값을 결정한 후 동결하여, 원래 test 분할(2317건)에 단 1회 적용.

## 6. 실험 결과 및 재현성 검증

### 6.1 개발 탐색 관찰 (Development Readout, 1750건)
- **DUP**: FPR 0.89% ± 0.11%, Recall 97.03% ± 0.70%
- **FLIP**: FPR 0.68% ± 0.15%, Recall 96.18% ± 0.56%
- 5개 시드 누적 사건 기준 FLIP은 오탐 25건 해결 vs 10건 신규 발생으로 순 오탐 감소(15건)를 보여 개발 단계에서는 유망해 보였다.

### 6.2 U5 후속 평가 결과 (원래 test 분할, 2317건)
새로 재학습된 U5 모델들을 원래 test 분할에서 검증한 결과:

| 실험군 (Arm) | 코호트 규모 | 재현율 (Recall) | 오탐률 (FPR) | F1-Score | Brier Score |
|---|---|---|---|---|---|
| **BASE** | 6680건 | 97.82% ± 0.99% | 0.60% ± 0.32% | 0.9814 ± 0.0056 | 0.0091 ± 0.0027 |
| **DUP** | 6961건 | **97.88% ± 0.48%** | **0.44% ± 0.11%** | **0.9837 ± 0.0022** | **0.0090 ± 0.0016** |

### 6.3 재현 실패 분석
- 개발 탐색에서 관찰된 FLIP의 FPR 개선 경향은 U5 후속 평가에서 이어지지 않았다 (DUP 0.44% vs FLIP 0.46%, 차이: +0.01%p).

- FLIP의 통계적 우월성이나 동등성을 주장하지 않는다.

## 8. 공학적 의사결정 및 제약 사항

1. **FLIP 자동 채택 보류**: 후속 평가에서 이점이 확인되지 않은 복잡한 교란 기법(FLIP) 대신, 단순 대조군(DUP)을 다음 연구 비교 기준으로 유지한다.
2. **Two-track 사후 시뮬레이션 배제**: 개발셋 사후 관찰에 기반한 Two-track 규칙은 사후 편향 위험이 있으므로 본편 확증 성과에서 배제하였다.
3. **재현 파이프라인**: 모든 수치는 `reports/generated/submission_evidence_20260919.json`에서 유도되며, `python3 scripts/build_submission_evidence_20260919.py --check`로 검증 가능하다.
4. **남은 과제**: 향후 실서비스 적용을 위해서는 신규 시점의 외부 독립 코퍼스 검증, 현실 정상 자료 수집, 그리고 전수 사람 검수 보완이 필요하다.
