# SAS 저장소 정리 기록 — 2026-09-21

사용자가 발표·HTML·자료 수집과 기존 SAS GitHub 정리·푸시를 요청한 범위에서 작업했다.
최신 열람본은 [자료 모음](../materials/20260921/README.md)이며 SAS 실행 진입점은 유지했다.

## 배치와 보존

- 발표·대본·문답·포스터·프로젝트 설명·오류 진단·최신 결과 해석을 `materials/20260921/`에 모았다.
- 기존 `outputs/`의 공개 가능한 집계 HTML·PNG·CSV는 [과거 SAS 결과](../archive/sas_outputs_20260914/README.md)로 이동했다. 상대경로와 바이트를 보존했다.
- 루트의 과거 `MANIFEST.json`, `CHECKSUMS_SHA256.txt`는 [과거 전달 이력](../archive/manifests_20260914/README.md)으로 옮겼다. 현재 트리의 파일 목록이 아니다.
- 원문·URL 행 자료·개별 예측·검수 행·로그·출처가 확인되지 않은 교육용 행 자료는 Git 추적에서 제외했다. 로컬 파일은 원래 경로에 그대로 남겨 해시 일치를 확인했다.
- `sas/`와 최신 집계 전용 패키지의 SAS 코드·입력 CSV는 변경하지 않았다. 기존 실행은 별도 비공개 입력이 필요하며 새 clone만으로 원문 분석을 재현할 수 있다고 주장하지 않는다.

정확한 이동·제외 목록은 [정리 manifest](../manifests/repository_organization_20260921.json)에 있다.
공개본의 출처·복사·경로 변경은 자료 모음 manifest를 따른다.

## 실행 결과의 범위

최신 SAS 반환본은 로그, 집계 CSV, ODS 결과와 이미지 연결을 대조한 열람본이다.
SAS 코드를 새로 실행하거나 CAS·Visual Analytics에 게시한 작업은 아니다.
기존 슬라이드와 포스터는 작성 당시 판을 보존하므로 최신 해석 HTML을 후속 결과 자료로 함께 사용한다.

## 공개 범위와 남은 기록

이번 정리는 **현재 Git 트리**에 적용했다. 이전에 공개됐던 원문·행별 파일은
과거 커밋에 남아 있으며, 이번 작업을 개인정보의 완전한 삭제로 해석하면 안 된다.
Git 이력 재작성과 기존 clone의 삭제는 별도 조치이며 수행하지 않았다.
자료의 원본 수집·배포 권한이 새로 부여되는 것도 아니다.

현재 `reports/generated/`의 예전 export·inventory JSON은 당시 전달 시점의 메타데이터다.
이전 파일 수와 입력 경로를 현재 공개본의 구성으로 읽지 않는다.
최신 공개 자료의 목록은 `materials/20260921/`의 manifest, 정리 이력은 위 정리 manifest를 따른다.

## 검증

이동 전 SHA-256과 이동 후 파일을 대조하고, 추적 제외 파일이 로컬에 그대로 남아 있는지 확인했다.
자료 모음의 해시·상대경로·이미지·공개 제외 항목을 검사하고 저장소 변경을 통합했다.
공개 파일만 내보낸 별도 폴더에서 자료 모음·슬라이드 미리보기·최신 해설 화면을 확인했다.
다운로드 무결성 검사와 변조 거부 확인, 전체 공개 트리의 상대경로 검사도 통과했다.
날짜별 자료 사본의 원래 줄바꿈·SVG/ODS 공백은 `.gitattributes`로 보존해 출처 해시를 유지한다.
과거 결과와 최신 실험의 평가 역할을 합치거나 수치를 다시 튜닝하지 않았다.
