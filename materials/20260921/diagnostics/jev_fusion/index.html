KcBERT + Jev 결합 탐색 (집계 보고)

보고 버전: jev-kcbert-fusion-20260920-v1

고정 KcBERT 점수에 Jev 행동 확률과 오프라인 URL 특징을 더한 탐색 결과다. 기존 검증 자료를 재사용한 파일럿이며 새로운 독립 시험이나 서비스 성능 증거가 아니다.

핵심 결과

  • 분모는 스미싱 34건·정상 108건(자료 유도)이며, FP 1건당 FPR 간격은 0.0093다.
  • 기준선과 K가 이미 오류 0건이므로 KJ·KJU의 0건이 Jev 개선을 입증하지 않는다.
  • KU의 FP 1건은 KJU에서 사라지나 기준선도 0건이다.
  • Brier(낮을수록 좋음)는 rawK 7.04e-07로 가장 낮고, KJ(0.0014)는 K(0.0006)보다 높다. 검증 재사용 소표본이므로 일반 순위를 주장하지 않는다.

설계

StandardScaler + LogisticRegression(C=1,max_iter=2000,random_state=42) · 임계값 규칙: calibration FPR <= 1%; max recall, min FP, highest threshold. K/J 입력은 동일한 가공 126토큰 접두어이며, URL 특징은 전체 SMS에서 추출되어 접두어 밖 정보를 포함할 수 있다.

한계

  • 검증 자료를 재사용한 탐색 파일럿이며 새로운 독립 시험이나 서비스 성능 증거가 아니다.
  • 새로운 독립 시험 자료가 없으며 readout은 검증 자료 재사용이다.
  • Jev API 사용량·지연 수치는 검증된 성공 응답 체크포인트 합산값만 표시한다. 합성 사전점검과 실패 호출은 제외하며 재사용 동일 요청은 1회만 집계한다.
  • 정상 분모가 유한하여 FPR은 양자화된다. readout의 FPR 1% 이하 달성을 보장하지 않는다.
  • KcBERT 확률과 Jev 특징은 고정 입력이며 설명문·원문은 제외한다.
  • URL 특징은 전체 SMS에서 추출되어 K/J 접두어 밖 정보를 포함할 수 있다.
