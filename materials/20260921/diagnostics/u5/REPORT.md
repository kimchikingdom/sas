  - *안내: 코퍼스 레이블은 연구용 기준 데이터이며 개별 메시지의 실제 적법성이 독립적으로 재검증된 것은 아닙니다.*

## 2. 3대 주요 기술적 관찰

### 2.1. 토크나이저 128 토큰 절단 코호트의 탐지율 대조
KcBERT 모델의 최대 입력 길이를 128 토큰(특수 토큰 포함)으로 설정함에 따라 전체 2,317건 중 331건(14.29%)에서 절단(Truncation)이 발생했습니다.
- **DUP 조건 가시 스미싱(<=128 토큰, 595건 x 5시드 = 2,975 이벤트)**:
  - 탐지 재현율(Recall): **99.2941%** (2,954 / 2,975)
  - 미탐률(FNR): **0.7059%** (21 / 2,975)
- **DUP 조건 절단 스미싱(>128 토큰, 57건 x 5시드 = 285 이벤트)**:
  - 탐지 재현율(Recall): **83.1579%** (237 / 285)
  - 미탐률(FNR): **16.8421%** (48 / 285)
- **분석적 주의사항**:
  - 절단 그룹에서 미탐률이 높게 관찰되나, 이는 텍스트 길이, 주제 분포, 어휘 복잡도 등의 코호트 교란 요인(cohort confounding)이 함께 작용하므로 단순 인과관계("절단 때문에 발생했다")로 단정할 수 없습니다.

### 2.2. 구조적 메타데이터 불일치 (원시 IPv4 주소 스미싱 미탐)
- `has_url = 0`으로 분류되었으나 본문에 도메인 대신 점 표기 IPv4 주소(예: `192.0.2.1/...; 실제 주소와 다른 문서용 예시`)가 포함된 단일 스미싱 샘플이 확인되었습니다.
- 본 샘플은 DUP 5개 시드 모두에서 미탐(FN)되었을 뿐만 아니라, **BASE, DUP, FLIP 15개 모델 전수에서 100% 미탐(15-Model All Miss)** 되었습니다.
- 이는 URL 메타데이터의 포착 범위 문제입니다. 최신 U5 모델은 has_url을 입력으로 쓰지 않으므로, 표식 누락이 미탐을 일으켰다고 결론 내릴 수 없습니다.

### 2.3. 시드별 임계값 변동성 (Seed 202 Anomaly)
- DUP 조건의 검증셋에서 선택한 임계값은 타 시드(42, 101, 303, 404)가 `0.022 ~ 0.060`인 반면, **Seed 202는 `0.985776`** 으로 극단적으로 높게 형성되었습니다.
- 이는 모델 로짓 출력 분포가 난수 시드에 따라 크게 이동할 수 있음을 나타내며, 상이한 시드의 원시 예측 확률이나 마진(`Probability - Threshold`)을 동일 선상에서 직접 비교해서는 안 됩니다.
