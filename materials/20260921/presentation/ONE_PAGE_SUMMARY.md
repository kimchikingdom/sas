# ScamLens — 연구 요약

**정상 문자 오탐을 줄이려는 URL 편집 증강의 이점이 후속 평가에서도 이어지는가?**

BASE는 원본 fit, DUP는 선택 문자의 원문 추가, FLIP은 같은 문자의 URL 편집문 추가다.
DUP와 FLIP은 라벨을 보존하고 학습 예산을 맞췄다. 임계값은 calibration에서 전체
정상 FPR 상한 조건으로 선택한 뒤 고정했다. 이 상한은 test 성능 보장이 아니다.

## SAS에서 먼저 확인한 것

문자 단독·고정가중 결합·OOF 메타 결합의 test AUC는 각각
0.9987, 0.9950,
0.9988였다. 문자−OOF 차이는
-0.00006, p=0.7233로 차이를 검출하지 못했다.
OOF는 메타 모형의 학습 입력이고 ROC 비교는 test 점수를 사용했다. 동등성 증명은 아니다.

## U5 후속 평가

원래 test 2,317건을 5개 시드에서 평가한 평균이다.
같은 문자를 반복 평가했으므로 시드 수만큼 독립 표본이 늘어난 것은 아니다.

| 조건 | Recall | FPR | Brier Score |
|---|---:|---:|---:|
| BASE | 97.82% | 0.60% | 0.0091 |
| DUP | 97.88% | 0.44% | 0.0090 |
| FLIP | 97.55% | 0.46% | 0.0117 |

개발 탐색에서 DUP→FLIP FPR은 0.89%→0.68%였다.
오탐 해소 25건·신규 오탐 10건은 메시지-시드 판정 수다.
U5에서는 FLIP의 낮은 FPR이 이어지지 않았다. 조건 간 우월성·동등성을 검정한 결과는 아니다.

**판단:** FLIP의 자동 채택을 보류하고 DUP를 다음 연구의 비교 기준으로 둔다.
실제 배포 모델을 교체한 결정은 아니다.

**한계:** U5는 새 가중치로 재학습한 평가이며 원래 test의 과거 모델 평가 이력이 있다.
외부 독립 평가와 사람 검수가 남아 있다. 공개본은 혼동행렬 지표와 저장된 시드 지표의
집계를 재검산하며, 비공개 원확률·학습 전체를 재현하는 패키지는 아니다.
