# SAS 과거 집계 결과

기존 outputs의 공개 가능한 HTML·PNG·집계 CSV를 원래 상대경로와 바이트 그대로 보존했다.

날짜는 전달 자료의 기준이며 폴더 안 모든 실행이 같은 날짜라는 의미는 아니다. 실패·중단 이력도 포함되어 있으므로 모든 파일을 성공한 결과로 해석하지 않는다. 로그와 행별 점수는 로컬 전용이다.

최신 반환 결과는 [2026-09-21 SAS 열람본](../../materials/20260921/sas-results/index.html)을 따른다.
