01. 실험 설계 (Matched Control Protocol)

엄격한 내적 타당성을 위해 모든 조건에서 사전학습 모델, 옵티마이저, 업데이트 횟수(654 updates)를 완전히 일치시켰습니다:

  • BASE (대조군): 원본 6,680행으로 학습한 기본 모델.
  • DUP (노출 통제군): 원본 6,680행 + 원본 URL 포함 281행 복제 (표본 추가 노출 효과 통제).
  • FLIP (교정 실험군): 원본 6,680행 + URL 마스킹/변형 281행 라벨 보존 주입 (지름길 차단).

※ 임계값은 개발 리드아웃셋(1,750행)을 일체 보지 않고, 별도 보정셋(1,703행)에서 FPR ≤ 1.0% 기준으로 사전 결정되었습니다.

시드 42, 101, 202, 303, 404에서 보정셋(FPR ≤ 1.0%)으로 임계값을 고른 뒤, 개발 리드아웃 1,750행에서 한 번 읽은 결과입니다. 미사용 독립 테스트가 아닙니다.

03. 유사도 그룹 단위 불확실성 (Group-level Uncertainty)

개발 리드아웃 1,750개 메시지는 유사도 클러스터링을 통해 총 1,543개 그룹으로 묶여 있습니다 (단일 그룹 1,460개, 다중 그룹 83개). 그룹 단위의 시드 간 예측 변동성을 전수 집계했습니다.

그룹 단위 평균 표준편차

  • FLIP: 0.0058 (전체 최저 변동성)
  • DUP: 0.0062
  • BASE: 0.0077

FLIP은 1,460개 단일 그룹에서도 0.0053으로 가장 일관된 결정을 유지했습니다.

확률 보정 신뢰도 (Brier Score)

  • FLIP: 0.01158 ± 0.00118 (최저 MSE 오차)
  • DUP: 0.01218 ± 0.00156
  • BASE: 0.01273 ± 0.00077

FLIP 조건은 모델 출력 확률값 자체가 실제 정답(0/1)과 가장 밀접하게 보정되어 있음을 입증합니다.

04. 실패 사례 및 전이 심층 분석 (Failure Case Study)

1,750개 샘플에 대해 DUP 대비 FLIP의 판정 전이를 전수 추적하여, 오탐 해소의 구체적 이점과 정탐 손실의 근본 원인을 규명했습니다.

전이 유형 판정 건수 고유 메시지 URL 있음 비율 대표적 텍스트 패턴 및 원인
오탐 해소 (Resolved FP) 25건 14개 92.0% (23건) 이번 자료의 택배·지자체·은행 안내처럼 URL이 있는 정상 문자. 현업 오탐 전부를 막았다는 뜻이 아님
정탐 손실 (Lost TP) 22건 9개 63.6% (14건) "박은주(백년요가) [url]"(15자) 등 스미싱 단서가 희박한 극단적 단문 및 정상과 유사한 쿠폰 문자
신규 오탐 (New FP) 10건 7개 20.0% (2건) URL 없는 정상 문자 중 "보안코드", "상담예약", "국제발신" 등 특정 키워드에 과민 반응
미탐 구제 (Rescued FN) 8건 6개 50.0% (4건) URL 없는 청첩장 사칭 및 주식 리딩방 문자를 FLIP이 본문 문맥으로 정탐 구제

05. 이중 경로(Two-track) 동적 신뢰도 게이팅 실증 결과

이미 학습된 FLIP 확률과 DUP 확률을 len < 35이고 URL이 있는 행에서만 섞는 사후 시뮬레이션입니다. Track 2는 별도 구조 분류기가 아닙니다. 규칙은 실패 분석을 본 뒤 같은 개발 리드아웃에서 점수를 냈습니다.

모델 / 아키텍처 Recall (재현율) FPR (오탐률) F1-Score Brier Score 평가
Two-track Gated 96.55% 0.75% 96.66% 0.01136 세 비교 중 평균 F1·Brier가 가장 좋음. 같은 개발 리드아웃
FLIP Baseline 96.18% 0.68% 96.62% 0.01158 오탐 억제 우수하나 단문 정탐 손실 존재
DUP Baseline 97.03% 0.89% 96.62% 0.01218 이 표의 임계값은 게이팅 스크립트가 보정셋을 다시 적용한 값

게이팅 평균은 FPR 0.75%, F1 96.66%, Brier 0.01136입니다. FLIP 대비 F1 차이는 약 0.12%p입니다. 독립 테스트가 아닙니다.
