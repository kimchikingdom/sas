# ScamLens 결과 해석 보고서

작성 기준: 2026-09-21 · 검증된 SAS 반환 결과와 공개 집계 정본

> 기존 평가자료에서는 높은 탐지율을 보였지만, 외부 스미싱에서는 취약점이 드러났다.
> 입력 처리와 JEV 결합을 시험했으나 안정적인 추가 이득은 확인되지 않아 기존 기준선을 유지한다.

이 문서는 기존 평가, 외부 자료 진단, JEV 비교·결합, SAS 검증을 구분해 설명한다.
수치는 생성기가 원본 집계에서 계산한다. 과거에 작성된 세부 문서의 SAS 실행 대기 문구보다
아래의 최종 반환 검증 상태가 우선한다.

## 1. 먼저 알아둘 용어와 평가 범위

- **오탐(FP)**: 정상 라벨 문자를 스미싱으로 판단한 경우.
- **미탐(FN)**: 스미싱 라벨 문자를 정상으로 판단한 경우.
- **탐지율(재현율)**: 스미싱 중 탐지한 비율. 전체 정확도와 다르다.
- **오탐률(FPR)**: 정상 문자 중 잘못 경보한 비율. 분모는 정상 문자다.
- **시드**: 학습의 난수 설정. 같은 문자를 여러 시드로 평가해도 서로 다른 문자로 세지 않는다.
- **토큰**: 모델이 문장을 나누어 읽는 단위. 글자 수와 같지 않다.

| 평가 | 목적 | 해석 범위 |
|---|---|---|
| 기존 U5 자료 | 학습 조건 비교와 오류 분포 점검 | 과거 평가 이력이 있는 자료의 사후 진단 |
| KISA 외부 자료 | 고정 모델의 외부 사례 탐지와 입력 개입 진단 | 최초 외부 평가와 같은 자료를 재사용한 후속 진단을 구분 |
| 정상 후보 | 입력 수정 후 경보 증가 점검 | 기존 개발자료의 출처 라벨 기준 회귀 검사 |
| JEV 가상 대체 | 기존 판단을 바꿀 때의 이득·손실 확인 | 오류를 과대표집한 선택 표본 |
| JEV 특징 결합 | 보조 특징의 추가 효과 확인 | 기존 검증자료를 나눈 탐색 평가 |

원래 코퍼스 라벨은 연구의 비교 기준이다. 개별 사례의 실제 사기 여부를 독립적으로
확정했다는 뜻은 아니며, 특히 정상 후보를 인증된 정상 자료로 표현하지 않는다.

## 2. 기존 평가에서는 DUP가 평균적으로 가장 나았다

평가자료는 총 **2,317건**으로, 정상 **1,665건**, 스미싱 **652건**이다.
아래는 같은 평가자료를 사용한 **5개 시드의 평균**이므로 건수에 소수점이 있다.

| 학습 조건 | 평균 오탐 | 평균 미탐 | 평균 탐지율 | 평균 오탐률 |
|---|---:|---:|---:|---:|
| BASE: 원본 학습 | 10.0건 | 14.2건 | 97.82% | 0.60% |
| DUP: 선택 원문 추가 | 7.4건 | 13.8건 | 97.88% | 0.44% |
| FLIP: 선택 문자의 URL 편집문 추가 | 7.6건 | 16.0건 | 97.55% | 0.46% |

BASE는 원본으로 학습하고, DUP는 선택한 문자의 원문을 추가한다.
FLIP은 같은 선택 문자의 URL 편집문을 추가하되 원래 정답 라벨을 유지한다.
**FLIP은 정답 라벨을 반전한 조건이 아니다.**

이번 자료에서는 URL 편집문을 추가하는 방식이 원문을 추가하는 방식보다 나아지지 않았다.
DUP의 평균 오탐·미탐이 더 적었지만, 통계적으로 우월하거나 외부 환경에서도 더 좋다고
확정한 것은 아니다. 평가자료를 보고 규칙이나 임계값을 다시 맞추지 않는다.

## 3. 긴 문자에 미탐이 집중됐지만 단일 원인은 확정되지 않았다

DUP 모델의 입력 한도 **128토큰**을 기준으로 나누면 다음과 같다.

| 스미싱 문자 구분 | 고유 문자 수 | 평균 미탐 | 미탐률 |
|---|---:|---:|---:|
| 입력 한도 이내 | 595건 | 4.2건 | 0.71% |
| 입력 한도 초과·뒤쪽 절단 | 57건 | 9.6건 | 16.84% |

입력 한도를 넘은 스미싱은 전체의 **8.7%**지만,
평균 미탐의 **69.6%**가 여기에 집중됐다.
분모가 같은 시드들의 오류 합계로 비중을 계산했으며, 반복 판정을 고유 문자 수로 표시하지 않는다.

이는 취약한 입력 조건을 보여준다. 다만 긴 문자에 특정 문체·출처·사기 유형이 함께
몰려 있을 수 있으므로, 뒤쪽 내용이 잘리는 현상만을 원인으로 확정할 수는 없다.

정상 문자에서는 URL이 있는 집단의 평균 오탐률이 **2.01%**, 없는 집단은
**0.10%**였다. URL이 있는 정상 안내를 구별하는 능력을 더 점검할 근거다.
이 비교만으로 모델이 URL 하나만 보고 판단한다고 결론 내리지는 않는다.

## 4. KISA 외부 자료에서는 기존 성적이 그대로 이어지지 않았다

기준 시드 42는 KISA 고유 스미싱 **22건 중 13건을 탐지하고
9건을 놓쳤다**. 탐지율은 **59.09%**다.
유사한 문자끼리 묶어 대표만 남긴 **18건**에서는 **9건 탐지,
9건 미탐**, 탐지율 **50.00%**였다.
대표 집합은 고유 문자 집합의 부분집합이므로 두 집합을 합산하지 않는다.

기존 평가의 높은 탐지율이 새 외부 사례에서도 보장되지는 않았다.
그러나 자료 수가 적고 구성도 달라 실제 환경 전체의 탐지율로 일반화할 수 없다.
기존 표는 여러 시드의 평균이고 여기서는 기준 시드 결과라는 차이도 있다.
KISA 자료에는 정상 문자가 없으므로 이 자료만으로 오탐률을 계산할 수 없다.

### 입력을 바꾸면 해결되는가

다음은 같은 기준 시드의 결과다. 정상 후보의 경보 수는 실제 서비스 오탐률이 아니다.

| 입력 처리 | KISA 탐지 / 미탐 | 탐지율 | 정상 후보 250건 중 경보 | 기존 대비 새 경보 |
|---|---:|---:|---:|---:|
| 기존 128토큰 | 13 / 9 | 59.09% | 11건 | 0건 |
| 화면 잡음 삭제＋128토큰 | 13 / 9 | 59.09% | 11건 | 0건 |
| 읽는 범위를 300토큰으로 확대 | 13 / 9 | 59.09% | 24건 | 13건 |
| 화면 잡음 삭제＋300토큰 | 14 / 8 | 63.64% | 24건 | 13건 |
| 화면 잡음 가림＋128토큰 | 13 / 9 | 59.09% | 11건 | 0건 |
| 화면 잡음 가림＋300토큰 | 16 / 6 | 72.73% | 24건 | 13건 |
| 앞부분·뒷부분을 합쳐 128토큰 | 13 / 9 | 59.09% | 17건 | 6건 |

- **화면 잡음 삭제**는 OCR에 섞인 상태바·작성창 등으로 확인한 구간을 제거한다.
  삭제는 뒤쪽 토큰의 위치와 읽히는 범위도 바꿀 수 있다. 배포용 자동 정제 규칙은 아니다.
- **화면 잡음 가림**은 위치와 길이를 유지한 채 해당 토큰을 `[UNK]`로 바꾼다.
  자연스러운 정제문과 다르며, 치환 자체가 모델에 영향을 줄 수 있다.
- **300토큰 확장**은 128토큰으로 학습한 모델이 읽는 범위를 늘리는 실험이다.
  긴 입력으로 새로 학습한 모델의 성능을 검증한 것은 아니다.

화면 잡음 삭제만으로는 기준 시드의 미탐이 해결되지 않았다. 길이만 늘리는 조건에서도
탐지 개선 없이 정상 후보 경보가 늘었다. 잡음 가림과 길이 확장을 함께 적용하면 일부
미탐이 복구됐지만 정상 후보 경보도 늘었고, 다른 시드에서 개선 폭이 일정하지 않았다.
**잡음을 지우거나 더 길게 읽히면 해결된다는 단순한 개선 가설은 지지되지 않았다.**

사전에 지정한 개선 후보 `head_tail128`은 평가한 모든 시드에서 미탐 복구가 없고
새 정상 후보 경보가 발생해 채택 기준을 통과하지 못했다. 관측 후 가장 좋아 보이는
다른 조건을 승자로 바꾸지 않고, **기존 `original128`과 고정 임계값을 유지한다.**

후속 개입 진단은 이미 평가한 KISA 자료를 재사용했다. 정상 후보도 기존 학습·검증
자료에서 뽑은 개발용 후보다. 따라서 개선 효과의 신규 독립 시험이나 독립 오탐률
평가로 표현하지 않는다. 조건별 상세 근거는
[KISA 실측 해석서](KISA_DIAGNOSTIC_INTERPRETATION_20260921.md)에 있다.

## 5. JEV 자동 대체와 특징 결합은 별개의 실험이다

### KcBERT 판단을 JEV로 바꾸는 방식

오류 사례를 과대표집한 선택 표본 **88건**에서, 시드 42 기준
기존 오탐 **8건**을 해소하는 대신 **새 미탐 41건**이 생겼다.
기존 정답 판정 중 **1건**은 JEV 보류로 바뀌었다.

현재 질문과 판정 규칙으로 자동 대체하는 방식은 채택하기 어렵다.
JEV에 묻는 명시적 위험 요구의 유무와 데이터의 스미싱 정답은 정의가 다르다.
따라서 이 결과를 JEV 모델 자체의 일반 성능으로 확대하지 않는다.
불일치 사례를 사람에게 넘기는 방식도 실제 사람이 검토해 오류를 고친 성과는 아니다.

### KcBERT 점수에 JEV 특징을 추가하는 방식

별도의 탐색 평가자료 **142건**(정상 108건,
스미싱 34건)에서는 다음과 같았다.

| 결합 조건 | 오탐 | 미탐 |
|---|---:|---:|
| KcBERT 기준선 | 0건 | 0건 |
| KcBERT 점수만 재결합 | 0건 | 0건 |
| KcBERT＋JEV | 0건 | 0건 |
| KcBERT＋URL 특징 | 1건 | 0건 |
| KcBERT＋JEV＋URL 특징 | 0건 | 0건 |

기준선부터 오류가 없었으므로 JEV의 추가 탐지 이득을 입증할 여지가 없었다.
기존 검증자료를 역할별로 나눈 탐색 평가이며, 새 독립 시험이나 실제 환경에서
완벽하게 탐지한다는 증거가 아니다. URL 특징은 오프라인 문자열 분석으로 얻었고,
이 결과를 얻기 위해 URL에 접속하지 않았다.

## 6. SAS 검증의 의미

반환된 실행에서 **4단계 모두 완료**를 확인했다.
ZIP **55개 파일**의 무결성을 확인하고 반환 CSV·HTML의 수치를 원본 집계와 대조했다.
그래프 **35개**도 직접 검수했다.

SAS는 모델을 새로 학습한 것이 아니라 오류·조건별 차이·모델 비교 집계를 재계산하고
시각화했다. **SAS 계산·반환 검증 통과와 탐지 성능 개선은 서로 다른 판단이다.**
일부 보고서의 서버 이미지 경로는 반환 원본을 보존한 채 로컬 열람본에서 수정했다.
향후 이미지 경로를 고친 SAS 소스의 서버 재실행과 CAS·VA 검증까지 완료했다는 뜻은 아니다.

## 7. 발표에서 사용할 결론과 남은 과제

> 기존 평가에서 높은 탐지율을 보인 모델도 외부 스미싱에서는 미탐이 발생했습니다.
> 긴 입력과 URL 포함 정상 문자에서 취약 조건을 확인하고, 입력 처리와 JEV 결합을 실험했습니다.
> 그러나 안정적인 개선과 추가 이득이 확인되지 않아 기존 기준선을 유지했습니다.
> Python 집계와 SAS 반환 결과를 대조해 수치와 보고서의 재현성을 확인했습니다.

현재 입증한 것은 **오류가 집중되는 조건, 시도한 수정의 이득과 부작용, 채택하지 않을
방법을 가려낸 검증 과정**이다. 각 오류의 원인을 하나로 확정하거나 실서비스 안전성을
입증한 단계는 아니다. 실패한 개선 시도와 오탐 증가도 발표에서 그대로 설명한다.

다음 단계는 새 정상·스미싱 자료로 평가 범위를 넓히고, 개선안을 평가 전에 고정한 뒤
독립 자료에서 비교하는 것이다. 긴 입력 처리와 보조 모델의 효과는 정상 문자 경보 증가까지
함께 판단해야 한다. 지금 본 자료를 반복해서 보며 규칙·임계값을 맞춘 결과를 독립 개선
성과로 제시하지 않는다.
